# Posterior TFRs by stimulated STN side

Run `run_stim_laterality_tfr.py` to create two PDFs, one for **RIGHT
STN stimulation** and one for **LEFT STN stimulation**, with one page
per successfully processed participant and exactly five TFR panels.

## Prerequisites

- Clean cue-locked epoch files from the EEG-all-channels pipeline:
  `no-stim` and `stim` for each participant.
- A recent, validated `trial_alpha.csv` generated by
  `analysis/subject/EEG_posterior_channels/block_preparation/B03_prepare_block_alpha.py`.
  It supplies the **confirmed** left/right STN stimulation period
  and the original cue-epoch index. Its trial indices must cover each
  cleaned condition exactly once; if cleaning changes, rerun B03.

## Run (from the repository root)

```bash
python analysis/group/EEG_posterior_channels/stim_laterality/run_stim_laterality_tfr.py \
    --subjects 101 102 103 105 106 107 108 112 113 114 115 116 118 120 121 123
```

Mac is the default platform. Optional flags include `--platform bluebear`,
`--project-root PATH`, `--trial-csv PATH`, `--output-dir PATH` and
`--n-jobs 4`.

## Exact data selection

Each report compares **only** the one period where the corresponding
STN side was ON against **both OFF periods** from that participant.
The LEFT stimulation period is never pooled with the RIGHT stimulation
period. Both cue directions are pooled; no cue-side conditions are
compared. All comparisons use the participant's own trials.

The eight original posterior sensors are PO3, POz, PO4, O1, Oz, O2,
PO7, PO8. For hemisphere-specific figures, the actual sensor groups
are:

- **Left**: PO3, PO7, O1.
- **Right**: PO4, PO8, O2.
- **Midline POz and Oz**: excluded from left/right contrasts because
  they cannot meaningfully be assigned to either hemisphere.

Sensors missing or marked bad in either ON or OFF are omitted from both
conditions. The participant page records the actual sensors used.
If one hemisphere has no valid shared sensors, the participant is
skipped rather than silently replacing electrodes.

## Five TFRs per participant page

The layout has the first four panels in a 2-by-2 grid and the fifth
panel full-width at the bottom:

1. Left posterior sensors: `ON_baselined - OFF_baselined`.
2. Right posterior sensors: `ON_baselined - OFF_baselined`.
3. Left posterior sensors: `ON_unbaselined - OFF_unbaselined`.
4. Right posterior sensors: `ON_unbaselined - OFF_unbaselined`.
5. **ON only**: `right-sensor power - left-sensor power`, unbaselined.

For panels 1-2, each condition is independently baseline corrected to
**-0.3 to -0.1 seconds** with percent change at each sensor/frequency.
After correction, power is averaged across included sensors, then
OFF is subtracted from ON. The unit is **percentage points**.

For panels 3-5, **no baseline correction** is used: averaged linear
multitaper power is subtracted, and the unit is **microvolt squared**,
assuming MNE supplies power in V². These maps are not percent changes
and are not ratios.

Averaging follows the same multitaper parameters as the existing G03
posterior workflow: 2-31.5 Hz in 0.5 Hz steps, `n_cycles=freq/2`,
`time_bandwidth=2.0`, `decim=2`. Power is averaged over retained
trials first, before sensor averaging. Displayed times: -0.5 to
1.5 seconds relative to cue onset, with cue onset marked at zero.

The colour scale is symmetric about zero and chosen from the
participant's displayed data (shared across the two baseline-corrected
panels, and shared across the three unbaselined panels). Therefore,
limits need not match between participants. These are **descriptive**
plots with no significance tests.

## Output

Both PDFs are written under:

`<PROJECT_ROOT>/derivatives/reports/group/EEG_posterior_channels_stim_laterality/`

- `posterior_TFR_right_STN_ON.pdf`
- `posterior_TFR_left_STN_ON.pdf`

Only these PDFs are written. The terminal reports skipped participants
and errors. A participant is never assigned to the wrong stimulation
side to fill a missing page.

## Limitations

The two ON periods may occur at different chronological positions,
and the OFF reference pools both OFF periods. These plots alone do not
control for time/order/carryover, nor imply a causal hemispheric
difference. Epochs must be in the same EEG reference scheme for the
ON/OFF comparisons.
