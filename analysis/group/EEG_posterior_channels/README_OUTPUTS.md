# Group posterior EEG analysis outputs

## EEG_posterior_channels_block_mapping

Generated by `G04_prepare_block_alpha.py`.

- `trial_alpha.csv`: one row per retained cue epoch. Includes participant, task block (1-8), stimulation period (1-4), DBS side/ON status, cue direction, absolute alpha power in V², individual peak, channel count, BIDS cue time, and whether the onset was inferred. **This is the input to S02.**
- `block_summary.csv`: per-participant, per-task-block trial count, mean absolute alpha power, block timing and onset provenance. Not used by S02.
- `mapping_audit.csv`: per-participant and condition validation counts, original/concatenated/piecewise timing model, sample offset(s), segment split, and missing/inferred boundaries. Use for QC.
- `G04_error_log.csv`: failed/skipped participants, stage, error type, traceback and timestamp. A failure does not mean the participant is permanently excluded.
- `diagnostics/sub-*_timing_original.csv` and `*_concatenated.csv`: candidate event-alignment residuals produced on failure. Nearest BIDS cues are **not verified assignments**.

G04 overwrites these group CSVs on each run. Use `--output-dir` to isolate test runs. Confirmed stimulation orders are stored separately in `analysis/subject/stimulation_sequence_confirmed.json`.

## absolute_alpha_block_permutation

Generated by `S02_absolute_alpha_block_permutation.py` and optional companion scripts.

- `participant_effects.csv`: one row per included participant; alpha peak, ON/OFF retained trial counts, absolute ON-minus-OFF alpha power in V². Participants have equal weight in the group statistic.
- `permutation_null.csv`: one group ON-minus-OFF statistic in V² for each block-label permutation.
- `absolute_alpha_block_permutation.pdf`: primary S02 methods, permutation distribution and participant effects.
- `participant_percentage_effects.csv`: optional sensitivity analysis; participant ON-minus-OFF as percentage of that participant's OFF mean.
- `permutation_null_percentage.csv`: optional permutation null for the group mean percentage change; OFF denominator is recalculated for every permutation.
- `leave_one_out_absolute.csv`: optional influence check; repeats the absolute permutation analysis after omitting each participant.
- `absolute_alpha_permutation_figure.{pdf,png,svg}`: presentation-ready absolute null distribution and observed group mean.
- `percentage_alpha_permutation_figure.{pdf,png,svg}`: corresponding optional percentage plot.

## Why sensitivity analyses?

The primary raw V² difference can be dominated by participants with large EEG power. Percentage changes put participant effects on a relative scale, but may be unstable when OFF power is very small; they do not automatically improve causal validity. Leave-one-out results reveal whether significance depends on one participant; these are diagnostic, not separate confirmatory tests.

## One-sided tests

A directional alternative (ON < OFF) should ideally be specified before examining results. A one-sided period-label permutation test counts null statistics <= observed. A one-sided participant-level t-test instead assumes approximately normally distributed participant differences. Neither should replace the original two-sided primary result merely because its observed direction is negative. Both depend on a defensible design and inclusion criteria.
