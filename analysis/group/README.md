# Group Analysis Pipeline

This folder contains all scripts used for the **group-level EEG analyses** for the STN stimulation project.

The group pipeline is designed to mirror the single-subject pipeline while providing two complementary methods of combining data across participants.

---

# Overview

Two independent analyses are performed.

## 1. Concatenated epochs

Script

```text
G01_concatenated_epochs_report.py
```

Purpose

All cleaned epochs from all analysed participants are concatenated together before computing ERP and TFR.

Conceptually, this treats every retained trial as an independent observation.

Therefore, participants with more retained epochs contribute proportionally more to the final result.

This analysis is useful for descriptive visualisation and maximising signal-to-noise ratio.

Outputs

* concatenated epochs
* ERP
* TFR
* stimulation minus no-stimulation difference
* stimulation ratio
* persistent PDF report

---

## 2. Grand average across participants

Script

```text
G02_grand_average_report.py
```

Purpose

Each participant is analysed separately.

Subject-level ERP and TFR estimates are then combined using

```python
mne.grand_average()
```

Each participant contributes equally regardless of the number of retained epochs.

This analysis provides the conventional group-average visualisation.

Outputs

* grand-average ERP
* grand-average TFR
* stimulation minus no-stimulation difference
* stimulation ratio
* persistent PDF report

# Requirements

Before running any group analyses, every participant must have completed the full subject-level analysis pipeline.

Required outputs for every participant are

```text
*_epo-cue.fif

*_evo-cue.fif

*_evo-grating.fif

*_both_*_tfr.h5

*_left_*_tfr.h5

*_right_*_tfr.h5
```

These files are generated by the subject pipeline.

---

# Selecting participants

Participants are defined in

```text
subjects_for_group_analysis.json
```

Example

```json
{
    "subjects": [
        "sub-115",
        "sub-116",
        "sub-118",
        "sub-119"
    ]
}
```

To include additional participants simply append them to this list.

No code changes are required.

---

# Running the analyses

Run the concatenated analysis first

```bash
python G01_concatenated_epochs_report.py
```

Then run the grand-average analysis

```bash
python G02_grand_average_report.py
```

The two analyses are independent.

They may be run separately.

---

# Generated reports

Both scripts generate persistent reports using the project PDF helper.

Reports are stored inside

```text
derivatives/
    reports/
        group/
```

Each report automatically records

* report type
* date
* analysed subjects
* number of analysed participants
* ERP figures
* TFR figures
* stimulation difference figures
* stimulation ratio figures

At the end of every analysis the script pauses and asks for

```text
Analysis notes
```

Any notes entered are permanently appended to the report.

This is intended for documenting observations discovered while inspecting the figures, such as

* unusually noisy participants
* excluded channels
* unexpected stimulation effects
* observations to revisit later

# Interpretation

## Concatenated epochs

Advantages

* maximises statistical power
* maximises signal-to-noise ratio
* useful descriptive visualisation

Limitations

Participants with more retained epochs contribute more heavily than participants with fewer retained epochs.

---

## Grand average

Advantages

* every participant contributes equally
* standard representation for group EEG analyses
* less influenced by participants with many retained trials

Limitations

Slightly lower signal-to-noise ratio than the concatenated analysis.

---

# Current scope

The current group pipeline performs descriptive analyses only.

Included

* ERP
* TFR
* stimulation vs no-stimulation comparison
* difference plots
* ratio plots

Not included

* Peak Alpha Frequency (PAF)
* Modulation Index (MI)
* statistical testing
* cluster permutation tests

These analyses may be added later without modifying the current descriptive pipeline.
